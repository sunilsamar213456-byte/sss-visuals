SSS VISUALS WEBSITE — PROJECT SOURCE

This is a React + Vite + Tailwind website customized from the supplied landing-page project.

DESIGN
- Preserved the original premium dark background.
- Kept the original lavender / violet, cyan and warm-amber gradient accents.
- Updated the brand identity to SSS VISUALS.

RUN LOCALLY
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in the extracted folder.
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown by Vite.

BEFORE PUBLISHING
- Replace the concept portfolio images/content with your own real work. Items are labelled as concept projects; do not present them as paid client case studies.
- Add your real business email and social profile links.
- Connect the inquiry form to a real email/form backend. The current form is a front-end preview and does not send submissions.
- Review service descriptions, pricing (currently custom quote), turnaround times, rights and terms so they match what you can actually deliver.
- Replace any stock video/photos with licensed assets or your own footage.

BUILD FOR DEPLOYMENT
Run: npm run build
The production output will be created in the dist/ folder.
